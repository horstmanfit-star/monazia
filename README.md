# Site Mona Dias – Nutricionista Integrativa

Landing page estática (HTML/CSS) publicada via GitHub Pages.

## Estrutura
- `index.html` – página principal
- `images/` – fotos e imagem de compartilhamento (og-image.jpg)
- `favicon.svg`, `robots.txt`, `sitemap.xml`, `.nojekyll`

## Antes de publicar
Troque `SEU-USUARIO` (e `mona-dias`, se o repositório tiver outro nome) pela URL real em:
`index.html` (canonical, og:url, og:image, JSON-LD), `robots.txt` e `sitemap.xml`.
